# 사랑이야기스튜디오 대전점 홈페이지

가족사진 · 증명·여권사진 · 프로필사진 사진관 홈페이지입니다.

## 파일 구성
- `index.html` — 홈 (대표 가족사진, 촬영 분야, 촬영 과정, 자주 묻는 질문, 오시는 길)
- `family.html` — 가족사진
- `id-photo.html` — 증명·여권사진
- `profile.html` — 프로필사진
- `gallery.html` — 갤러리 (사진 추가 방법은 파일 안에 적혀 있습니다)
- `js/site-info.js` — **전화번호·주소·영업시간·예약 링크** (이 파일만 고치면 모든 페이지에 반영)
- `css/style.css` — 색상·디자인
- `images/` — 사진

## 내 컴퓨터에서 미리 보기
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
실행 후 브라우저에서 http://localhost:8080 을 열어 주세요.
